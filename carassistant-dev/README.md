# Car Assistant Developer

**The newest development state of Car Assistant - for testing.** It is built from the `dev` branch of the same repository and may contain unfinished features.

The version looks like `0.5.1.3`: the first three numbers are the version that comes next, the last number counts the development steps towards it. When the version is released, it appears as the normal **Car Assistant** with the three-number version.

- It runs **next to** Car Assistant with its **own data** (a separate app): nothing of your real data is touched, nothing is shared. Use the *Car Assistant* app for everyday use.
- Do not give it the same network port as Car Assistant.
- You can try it with the demo car or restore a backup of one car into it.

Please report what you find: https://github.com/Matze89x/ha-car-assistant/issues
