# Car Assistant Developer

Same app as **Car Assistant**, built from the `dev` branch. Everything in the Car Assistant documentation applies: https://github.com/Matze89x/ha-car-assistant

- Own data folder: a separate app, you can run both side by side.
- Version `0.5.1.N`: the next release plus the number of development steps.
- Updates: when a new dev version appears in the store, press *Update*; the app is then built again from the newest `dev` state.
- Configuration options are the same as in Car Assistant.
- To move data in: make a backup of one car in Car Assistant and restore it here (or the other way round).
