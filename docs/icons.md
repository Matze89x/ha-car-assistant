# Icons for plugins and integrations

🇬🇧 English · [🇩🇪 Deutsch](icons.de.md)

A plugin, an integration, a page of an integration and an entry of a source's index may name an **icon**. Car Assistant draws every icon itself from one set - the [Material Design Icons](https://pictogrammers.com/library/mdi/) (the same names) - so nothing is loaded from the internet and a package carries no pictures.

- In `plugin.json`: `"icon": "wrench"` - the icon of the tile (Manage), of the page in the navigation bar and of its menu entry.
- In `index.json` of a source: `"icon": "wrench"` on the entry of the package - the icon of the tile in *Add*, before anything is installed. Use the same name in both.
- A name that is not in the set below is ignored (the tile then shows the default: a plug for plugins, a puzzle piece for integrations). Check yours with `python tools/check_plugin.py <folder>`.
