# Icons für Plugins und Integrationen

[🇬🇧 English](icons.md) · 🇩🇪 Deutsch

Ein Plugin, eine Integration, eine Seite einer Integration und ein Eintrag im Index einer Quelle dürfen ein **Icon** nennen. Car Assistant zeichnet jedes Icon selbst aus einem Satz - den [Material Design Icons](https://pictogrammers.com/library/mdi/) (dieselben Namen) -, es wird also nichts aus dem Internet geladen und ein Paket bringt keine Bilder mit.

- In der `plugin.json`: `"icon": "wrench"` - das Icon der Kachel (Verwaltung), der Seite in der Navigationsleiste und ihres Menüeintrags.
- In der `index.json` einer Quelle: `"icon": "wrench"` am Eintrag des Pakets - das Icon der Kachel unter *Hinzufügen*, noch vor der Installation. Nimm in beiden denselben Namen.
- Ein Name, der nicht in der Liste unten steht, wird ignoriert (die Kachel zeigt dann das Standard-Icon: einen Stecker bei Plugins, ein Puzzleteil bei Integrationen). Prüfe deine mit `python tools/check_plugin.py <Ordner>`.
